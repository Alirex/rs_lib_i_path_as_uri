# Security policy

## Supported versions

Only the latest release of `path_as_uri` (the newest `v*` tag) gets fixes.

## Reporting a vulnerability

Report it privately through GitHub: **Security** tab → **Report a vulnerability**
(<https://github.com/Alirex/rs_lib_i_path_as_uri/security/advisories/new>). Do not open a public issue for it.

A first answer comes within a week.
